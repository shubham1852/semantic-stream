# Contributing to SemanticStream

This is an academic research project. The codebase follows strict engineering
standards. Before contributing, read the architecture overview in README.md.

## Development Setup
See RUNBOOK.md for complete local setup instructions.

## Code Standards
- Python: type hints on all functions, Google-style docstrings, structlog
- React: functional components, Tailwind only, no inline styles
- All PRs must pass: pytest backend/tests/ (59 tests) and npm run lint
